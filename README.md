# JavaScript Fundamentals

This repository contains three small JavaScript projects created as part of my JavaScript learning task.

## Projects

### 1. Counter App
A simple counter application that allows users to increase, decrease, and reset a number. It demonstrates variables, functions, and DOM manipulation.

### 2. To-Do List App
A basic task manager where users can add and delete tasks. It demonstrates event handling, functions, and dynamic DOM manipulation.

### 3. Quiz App
An interactive quiz application with multiple-choice questions. It checks answers, tracks the score, and displays the final result.

## Concepts Practiced

- JavaScript variables and data types
- Functions and conditional statements
- Arrays and objects
- DOM manipulation
- Event handling
- Callbacks and promises basics

## Technologies Used

- HTML
- CSS
- JavaScript

## Learning Goal

The goal of these projects was to strengthen my JavaScript fundamentals through practical implementation and understand how JavaScript makes web pages interactive.
